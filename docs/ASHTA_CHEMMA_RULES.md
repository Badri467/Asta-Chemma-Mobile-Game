# Ashta Chemma rules record

Status: partial user-confirmed requirements. Full specification awaits Phase 3. These choices describe this project's intended family/regional profile, not universal claims about all traditions.

## Confirmed by the user
- Traditional 5×5 board with centre finishing square.
- Two to four players; four pawns per player.
- Four cowrie shells.
- Open-side scoring: 0 = 8 (Ashta), 1 = 1, 2 = 2, 3 = 3, 4 = 4 (Chemma).
- Chemma (4) releases one pawn.
- Ashta (8) releases two pawns.

Release placement, cost and optionality are not yet confirmed. Do not infer them from the release counts.
